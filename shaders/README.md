```
  /\_/\  
 ( -w- )  - "Remapping colors with style~"
  J   L
```

## Description
Custom semantic remapper using GLSL fragments.

## Channels
*   `$OUT`: Final output color map.
*   `$FILL`: Background/fill layer mask.
*   `$ACC`: Accent colors and glowing CRT scanlines.
*   `$TXT`: Raw text character outline data.
