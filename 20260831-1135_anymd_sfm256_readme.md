# 🕹️ Super FabiMeow 256-Bit Console APK & Sync Suite

Welcome to the definitive autonomous compilation pipeline for the **SFM-256 Virtual Console** (`@lorik/sfm256-virtual-console`).

## 🚀 Native Compilation & GDrive Export

1. **Dependencies:** Ensure your computer has the standard Android SDK (Platform 34) and Gradle 8.2+ installed.
2. **Execute Compile Loop:** Open your local Windows PowerShell terminal as Administrator and execute:
   ```powershell
   ./scripts/20260831-1133_sfm256_build_and_export_apks.ps1
   ```
3. **Outcome:** Web assets are compiled, Capacitor layers are synchronized, and the custom package-named binary (`net.artkitty.sfm256_v1.0.0_debug.apk`) is safely placed inside `G:\My Drive\myapks` handling folder spaces.

## 📡 GitHub Kat Syncing

- Drop your plain-text story blocks and game files (`.kat`) into `/kats/`.
- Merging to `main` automatically runs our GitHub Action to compile the global catalog `index.json` and host it live on your GitHub Pages registry!
