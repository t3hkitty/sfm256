## Description
Mixtmoji sound engine, Android MediaSession bindings, and external music synchronization integrations.

## Components
*   **MediaSession Bridge:** Integrates play/pause/skip and track metadata with Android's audio system.
*   **Spotify Deep Linker:** Enables quick deep-linking to user playlists/tracks via Spotify URIs.
*   **BPM Sync Engine:** Analyzes audio output to align chiptune animations and game speed with the track's tempo.
