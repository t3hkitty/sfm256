## Description
HID controls, touch-grid mapping, and mobile/accelerometer telemetry interface.

## Components
*   **Gamepad HID:** Bridge to physical USB/Bluetooth retro gamepads via the Web Gamepad API.
*   **Touch Grid:** Overlay mapping coordinates on screen to virtual inputs.
*   **Sensor Engine:** Connects mobile accelerometer and gyroscope data to virtual console controls.
