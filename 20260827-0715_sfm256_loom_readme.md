# 🐾 Super FabiMeow 256 Narrative Loom Dashboard

Welcome to the **Super FabiMeow 256-Bit Console & Creative Narrative Loom** repository!

This module provides a tactile, sensory-safe digital sanctuary designed to empower neurodivergent (AuDHD) creators [cite: 107]. It implements the chibi-inspired philosophy of **Rounded Plumpitude**, stripping away visual anxiety (0px margins) and replacing them with soft, rounded containers, calming pastel gradients, and gentle, RSD-safe interaction flows [cite: 107, 150].

## 🛠️ Components Built

1.  **Low-Threat Manifesto (`/content/`):** Outlines the full engineering rationale behind ASCII-focused parodies, the Symmetrical Banter Paradigm, and reclaiming AI strictly as a mechanical stylus [cite: 35, 42].
2.  **Loom Dashboard Component (`/src/components/`):** A comprehensive React modal featuring:
    *   **Monospace 144Hz Console:** Full command line interpreter (`help`, `p2`, `shake`, `clear`) with virtual Player 2 support [cite: 32, 40].
    *   **4-Track Audio Loom:** Ground your executive function by blending drums, character ticks, banter arpeggiators, and lead solo tracks synced to BPM [cite: 13, 27].
    *   **Lyric Gutter & Mondegreen Stamp (`[👂 + ❓]`):** Track canon lyric streams against misheard interpretations, instantly writing stamps into your Lexicon Vault [cite: 200, 201].
    *   **AMM-256 Raymarching Screen:** Simulate scene outlines compiled into 3D wireframe character projections [cite: 38].
3.  **Sticky state hooks (`/src/hooks/`):** Instant browser cross-tab synchronization and LocalStorage preference caching.
4.  **Deployment Engine (`/scripts/`):** Secure bash hook rsyncing builds to VPS servers and WebDAV nodes [cite: 131, 229].
